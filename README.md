## 📌 Deskripsi Project

Project ini dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS) pada semester 1. Melalui project ini, saya ingin mulai memahami dasar-dasar pemrograman dan penggunaan GitHub sebagai platform untuk menyimpan, mengelola, serta membagikan kode program.

### 🎯 Harapan Mahasiswa

Sebagai mahasiswa semester 1 yang baru pertama kali mengunggah project ke GitHub, saya berharap dapat memahami proses penggunaan GitHub, mulai dari membuat repository, menambahkan file, hingga melakukan commit dan push.

Saya juga berharap project ini menjadi langkah awal untuk meningkatkan kemampuan pemrograman, membangun kebiasaan mengelola project secara profesional, serta belajar berkolaborasi dengan teman-teman. Ke depannya, saya ingin terus mengembangkan project yang lebih baik dan bermanfaat sebagai bekal menjadi seorang Software Engineer.

## 📝 Langkah-Langkah Pengerjaan

1. Membuat akun GitHub sebagai platform untuk menyimpan dan mengelola project.
2. Membuat repository baru dengan nama *Project UTS Semester 1*.
3. Menambahkan file README.md sebagai dokumentasi project.
4. Mengisi file README.md dengan data diri, deskripsi project, harapan mahasiswa, dan langkah-langkah pengerjaan.
5. Menambahkan teks animasi salam agar tampilan repository lebih menarik.
6. Melakukan *commit* untuk menyimpan perubahan dan *push* untuk mengunggahnya ke GitHub.
7. Memeriksa kembali isi repository untuk memastikan semua file dan dokumentasi sudah tampil dengan benar.
8. Memastikan repository dapat diakses oleh dosen untuk keperluan penilaian UTS.
